DEXO3 fx-991ES PLUS 2nd Edition Web Calculator
================================================

RUN WITHOUT NPM
1. Extract the ZIP file.
2. Open the extracted DEXO3-FX991ES-PLUS folder.
3. Double-click index.html.

Optional local server:
1. Open Command Prompt in this folder.
2. Run: python -m http.server 8000
3. Open: http://localhost:8000

KEYBOARD
- 0-9: digits
- + - * /: arithmetic
- ^: power
- !: factorial
- ( ): parentheses
- Enter or =: calculate
- Backspace: delete
- Escape or Delete: clear
- Type letters to enter functions, e.g. sin(30), sqrt(144), log(100), ln(e), pi.
- Arrow keys navigate menus.

IMPLEMENTED
- Responsive proportional calculator layout
- Dot-matrix-style canvas LCD
- Basic arithmetic and precedence
- Parentheses, implicit multiplication, powers, factorial and percent
- Trigonometric and inverse trigonometric functions
- Hyperbolic functions
- Roots, logarithms, exponentials, absolute value
- DEG / RAD / GRAD setup
- Basic mode and setup menus
- Ans and basic variable/memory storage

NOT YET IMPLEMENTED
- Exact Casio Natural Display/fraction editor
- Complex, statistical, matrix, vector, base-N and equation solvers
- Numerical integration, differentiation and summation
- Exact Casio firmware behavior and original LCD font

This is an independent educational web calculator interface, not an official Casio product.
No software can be guaranteed bug-free; test important calculations independently.
